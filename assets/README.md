# Original artwork

All SVG illustrations, icons and brand marks were drawn in source for Job Matcher. Document layouts represent job input and resume comparison; kanban layouts represent the application tracker. Amber marks the next action or reward. No downloaded imagery or company logos are used.

Native PNGs are rendered from the original brand mark. Loading pulse, success feedback and confetti use Flutter animation and CustomPainter rather than Lottie JSON; no animation dependency is required.
